## 🌿 Sul Sul! Добро пожаловать в твою игровую студию

Хватит искать команды по разным сайтам — собери нужный чит, настрой параметры и скопируй его одним нажатием.

**The Sims 4 Cheat Studio PRO** — независимый помощник для игроков The Sims 4. В нём собраны каталог команд, поиск и интерактивные генераторы навыков, карьеры, отношений и семейного бюджета.

> 🟢 Программа подготавливает текстовые команды для ручного копирования в игровую консоль. Она не внедряет код в процесс игры, не меняет игровые файлы и не редактирует сохранения.

## 🎮 Как использовать чит-код

1. Запусти **The Sims 4** и загрузи семью.
2. Открой Cheat Studio PRO.
3. Найди нужную команду или сформируй её генератором.
4. Нажми **«Скопировать»**.
5. Вернись в игру и нажми **`Ctrl + Shift + C`**.
6. Для команд, которым нужен режим разработчика, сначала введи **`testingcheats true`**.
7. Вставь скопированную команду и нажми Enter.

Некоторые команды зависят от дополнений, версии игры, активного персонажа и текущей ситуации в игре. Перед экспериментами сохраняй резервную копию важного сохранения.

Можно выбрать собственные MP3 для приветствия и фоновой музыки. Если браузер поддерживает IndexedDB, выбранные файлы сохраняются в его локальном хранилище.

**Музыкальные файлы в репозиторий не включены.** Используй только аудио, на распространение которого у тебя есть права. Голосовой поиск и воспроизведение зависят от браузера, разрешений и его возможностей; офлайн-работа не гарантируется.
