# Changelog

All notable public project changes are documented here.

## [1.0.0] — Initial public package

- Published the HTML companion interface and the supplied Windows executable.
- Documented 103 cheat cards across 11 categories.
- Clarified that the skill data array contains 62 entries.
- Clarified that the career selector contains 36 career paths and 2 school-grade entries.
- Added English and Russian project documentation.
- Added GitHub issue templates and a release workflow that attaches the supplied EXE to a published GitHub Release.
- Added a standalone BAT helper to open the HTML source in the default browser.

## Documentation refresh — quick-reference positioning

- Clarified that the product is an independent searchable reference to built-in The Sims 4 console commands, designed to save players time searching for commands.
- Added a direct link to EA's official The Sims 4 Cheats FAQ in the README and browser interface.
- Added a four-language introduction banner to the browser version.
- Clarified that the app copies text for manual entry and does not inject into or modify the game.
- Kept the non-affiliation and EA policy notice clear; the project is not an EA product.
