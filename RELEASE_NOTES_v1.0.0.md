# ✨ The Sims 4 Cheat Studio PRO — v1.0.0

**Created by [Emin Mirkarimov](https://github.com/eminmirkarimov)**  
First public package — an independent quick-reference guide to built-in The Sims 4 console commands.

## 🎮 Your starter pack

A searchable command cheat sheet: find a built-in console command, read its explanation, use a generator where available, and copy the text for manual entry in the game. See [EA's official The Sims 4 cheat FAQ](https://www.ea.com/games/the-sims/the-sims-4/faq/cheats) for EA-published documentation.

- Windows app: `Sims4_Cheat.exe`
- Browser edition and source: `index.html`
- 103 command cards across 11 categories
- Skill generator with 62 skill entries
- Career generator: 36 career paths + 2 school-grade entries
- Relationship generator with adjustable value
- Household funds generator from 0 to 9,999,999 §
- Search, category filters and optional browser voice search
- RU / AZ / TR / EN translations
- Dark/light themes, animated interface, tooltips and UI sound effects
- Optional user-selected MP3 greeting and background audio

## ℹ️ Release notes

- The EXE is the prebuilt binary supplied by the author. This repository workflow attaches it to the Release; it does not rebuild it.
- The application is a command reference and prepares text commands for the player to enter manually in the game's own console. It is not a trainer, game patch or injection tool.
- Some commands may depend on game updates, packs or gameplay conditions.
- Voice recognition and audio playback depend on the browser and its permissions.
- No third-party music files are included.
- This is an independent fan-made project and is not endorsed by or affiliated with EA or Maxis.
