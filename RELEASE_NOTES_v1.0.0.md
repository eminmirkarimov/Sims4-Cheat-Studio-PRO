# The Sims 4 Cheat Studio PRO — v1.0.0

First public release package by **Emin Mirkarimov**.

## Included

- Windows executable: `Sims4_Cheat.exe`
- Browser edition and HTML source: `index.html`
- Cheat reference with 103 cards across 11 categories
- Skill generator with 62 skill entries
- Career and school generator: 36 career paths + 2 school-grade entries
- Relationship command generator with adjustable relationship value
- Household funds generator from 0 to 9,999,999 §
- Search, category filters and optional browser voice search
- RU / AZ / TR / EN interface translations
- Dark and light themes, animated interface, tooltips and UI sound effects
- Optional user-selected MP3 greeting and background audio

## Notes

- The EXE is the prebuilt binary supplied by the author. This repository workflow attaches it to the Release; it does not rebuild it.
- The application generates and copies commands. The player enters them in The Sims 4 cheat console.
- Some commands may require specific packs, game versions or gameplay conditions.
- Voice recognition and audio playback depend on the browser and its permissions.
- This is an independent fan-made project and is not affiliated with EA or Maxis.
